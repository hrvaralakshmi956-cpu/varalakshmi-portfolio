# Varalakshmamma H R — Portfolio Website

A responsive personal portfolio made with plain HTML, CSS, and JavaScript. It is designed to be edited in Visual Studio Code and published on Netlify or GitHub Pages.

## Files

- `index.html` — website content and sections
- `style.css` — colours, layout, and responsive design
- `script.js` — mobile navigation and current copyright year

## Run it in VS Code

1. Extract `varalakshmi_portfolio.zip`.
2. Open VS Code.
3. Select **File → Open Folder** and choose the extracted `varalakshmi_portfolio` folder.
4. Open `index.html`.
5. If you have the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**. Otherwise, open `index.html` directly in your browser.

## Personalise before publishing

- Check the email address, LinkedIn URL, GitHub URL, education details, and project descriptions.
- Add a professional photo only if you want one; the current hero section uses a designed initials card.
- Add project repository links after confirming the repositories are public.
- Keep all skill descriptions accurate to your experience.

## Publish

You can deploy the folder using Netlify Drop or create a GitHub repository and enable GitHub Pages. This project is static and does not need a backend.
